# OpenGame — versión preparada para Vercel

Es una web estática HTML/CSS/JavaScript. No requiere Node.js, compilación ni instalación de dependencias.

## Publicar en Vercel
1. Descomprime el ZIP.
2. Sube la carpeta `OpenGame-Vercel` a un repositorio de GitHub (los archivos `index.html`, `styles.css`, `app.js` y `vercel.json` deben quedar en la raíz del repositorio).
3. En Vercel, importa ese repositorio.
4. En **Build and Output Settings**, deja el Framework Preset en **Other** y deja vacíos **Build Command** y **Output Directory**. No necesitas instalar dependencias.
5. Pulsa **Deploy**.

Si ya tienes un proyecto de Vercel conectado a GitHub, sustituye los archivos de la raíz del repositorio por estos y vuelve a desplegar.

Nota: el catálogo está vacío intencionadamente; todavía no se han conectado juegos reales ni publicidad.
